# 신대견 (Ain)

**ML 엔지니어 | 신호 및 영상 분류 | 시스템 통합**

## 만들 수 있는 것

- CNN 기반 환경 소리 분류 시스템 (UrbanSound8K) + 라즈베리파이 배포 실험
- TensorFlow Lite 기반 객체 검출·추적의 PC/Raspberry Pi 공용 배포
- 실시간 영상 모니터링 시스템 (얼굴/신체 감지, Flask + OpenCV)
- Python-MATLAB 교차검증 ML 파이프라인 구축
- AR 기반 건물 인식 Android 앱 (Kotlin/Jetpack Compose)

## 기술 스택

`Python` `PyTorch` `TensorFlow` `TensorFlow Lite` `OpenCV` `Flask` `MATLAB/Simulink` `Kotlin` `Git`
